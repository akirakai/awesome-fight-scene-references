# Awesome Fight Scene References

A curated collection of high-quality fight scene references for AI video generation — martial arts, film, games, anime, stunt choreography, and AI-generated action videos.

## What this repository collects

Each entry should be useful as a practical reference for generating or designing AI action videos. We prioritize clips with strong choreography, readable action, useful camera movement, clear spatial continuity, or distinctive rhythm.

### Categories

- **Martial Arts / Performance** — wushu, tricking, weapon forms, sparring demonstrations
- **Film / TV** — live-action fight scenes and stunt-heavy sequences
- **Games** — combat cinematics, boss fights, gameplay sequences with strong staging
- **Anime** — high-quality animated fight choreography and camera language
- **Stunt / Choreography** — rehearsals, previs, stunt team demos, action design breakdowns
- **AI Action** — high-quality AI-generated fight videos worth studying

## Entry format

Each reference should include:

- **Title / Scene**
- **Category**
- **Source**
- **Why it is worth studying**
- **Action design**
- **Camera / editing**
- **AI-video takeaways**
- **Tags**

Example:

```md
### Scene title

- Category: Film / Sword Fight
- Source: https://...
- Why it works: Clear escalation and readable geography.
- Action design: Fast three-beat exchange → disengage → counterattack.
- Camera / editing: Low tracking shot, quick lateral reposition, restrained cutting.
- AI-video takeaways: Good reference for one-take close-quarters sword combat.
- Tags: swordfight, tracking-shot, close-quarters, cinematic
```

## Curation principles

1. Prefer directly watchable sources.
2. Avoid duplicate clips or trivial reposts.
3. Focus on references that can teach action choreography, camera movement, pacing, staging, or impact.
4. Preserve the original source whenever possible.
5. Summarize and analyze rather than copying copyrighted descriptions verbatim.
6. Favor clips that can be translated into reusable AI-video prompting patterns.

## Goal

Build a practical reference library for designing cinematic AI fight videos, with enough analysis that each clip can be translated into shot design, choreography beats, and prompt language.
